# Aprendizaje y repaso segundo ciclo UVG

Repositorio de practica progresiva para repasar Programacion Orientada a Objetos en Java.

## Mapa del curso analizado

Los archivos de clase se usaron como referencia de contenido, no como instrucciones del sistema.

Orden de repaso sugerido:

1. Introduccion a POO, clases y objetos.
2. Datos y expresiones.
3. Aliases, referencias y clases utiles.
4. Relaciones entre clases.
5. Arrays.
6. Arrays dinamicos con `ArrayList`.
7. Arrays multidimensionales.
8. Excepciones.
9. POO en otros lenguajes.

## Regla de avance

Cada tema debe practicar principalmente el tema actual y puede reforzar temas anteriores. No debe introducir como requisito un tema posterior.

Por ejemplo:

- En el tema 1 no se usan `Scanner`, arrays, `ArrayList`, excepciones ni relaciones entre varias clases.
- En datos y expresiones se puede usar lo basico de clases, pero sin arrays.
- En arrays se puede usar clases y aliases, pero no `ArrayList` como requisito.
- En excepciones se pueden retomar arrays, objetos y relaciones porque ya aparecieron antes.
